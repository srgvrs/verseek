# Arquitectura Técnica: Fase 3 (Editor Web Visual)

Este documento define la arquitectura, dependencias y flujo de datos para la Fase 3 del proyecto Verseek. El objetivo es construir un editor en tiempo real que visualice la métrica y las sílabas usando CodeMirror 6 y Web Workers.

## 1. Dependencias Necesarias
Antes de escribir código, instalar en el paquete `apps/web`:
*   `codemirror` (Core)
*   `@codemirror/view` (Para las decoraciones y widgets)
*   `@codemirror/state` (Para manejar el estado del editor)
*   `@codemirror/language` (Para el análisis de sintaxis)
*   `vite` (Ya está en el proyecto, pero se usará para el bundling del Worker).

## 2. Estructura de Archivos Propuesta
```text
apps/web/src/
├── main.ts                 # Punto de entrada de la app
├── editor.ts               # Configuración de CodeMirror 6 y UI
├── estado.ts               # Gestión del estado (Map de elecciones)
├── worker/
│   └── analisis.worker.ts  # Web Worker (ejecuta @verseek/motor)
└── ui/
    └── decoraciones.ts     # Lógica visual (cajas, colores, tooltips)
